# Agentes - Proyecto de Odoo Venezuela

Este es un proyecto de Odoo con módulos personalizados para Venezuela (l10n_ve).

## Contexto del Proyecto

- **Módulos personalizados**: Múltiples módulos l10n_ve_* para localización venezolana
- **Origen**: Migración desde Odoo v18
- **Objetivo**: Compatibilidad con Odoo v19/v20

## Instrucciones para la IA

- Este es un proyecto de Odoo. Al migrar de v18 a v19, prioriza el uso de la nueva sintaxis del ORM y asegúrate de que las vistas XML cumplan con los nuevos estándares de búsqueda.
- Al realizar cambios, mantener compatibilidad con la localización venezolana.
- Antes de modificar archivos, revisar la estructura existente del módulo.
